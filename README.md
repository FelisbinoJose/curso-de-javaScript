# Operadores

## Operadores ariméticos

- Subtração = -
- Multiplicação = \*
- Divisão = /
- Soma = +
- Pontencia = \*\*
- Resto da divisão = %
- Incremento = ++
- Decrimento = --

## Operadores de comparação

- Igualdade: ==
- Diferença: !=
- Igualdade restrita: ===
- Diferença restita: !==
- Maior: >
- Menor: <
- Maior igual: >=
- Menor igual: <=

## Combinando comparadores

- AND: &&
- OR: ||
- Negação: !
